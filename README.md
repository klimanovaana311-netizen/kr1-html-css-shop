# МебельДива — мастерская необычной мебели на заказ

## Описание

Сайт мастерской, которая изготавливает необычную мебель на заказ.
На главной странице представлены услуги, портфолио выполненных работ,
этапы сотрудничества и форма заявки.

## Структура проекта

- `index.html` – главная страница (услуги, портфолио, форма заявки);
- `css/style.css` – файл стилей;
- `images/` – изображения выполненных работ;
- `.gitignore` – список файлов, исключённых из Git;
- `README.md` – описание проекта.

## Используемые технологии

- HTML5 (семантическая разметка, формы);
- CSS3 (grid, flexbox, тени, hover-эффекты);
- Git;
- GitHub.
